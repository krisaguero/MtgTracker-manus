## 2026-08-22 Commander pricing audit

- MTGJSON’s official Deck model defines `commander`, `mainBoard`, `sideBoard`, `name`, `code`, `releaseDate`, and `sealedProductUuids` fields. The deck model documentation is at https://mtgjson.com/data-models/deck/.
- MTGJSON’s All Decks page is at https://mtgjson.com/downloads/all-decks/ and exposes individual JSON downloads including current Commander product filenames such as `AvengersAssemble_MSC.json`, `DoomPrevails_MSC.json`, `TheFantasticFour_MSC.json`, and `WakandaForever_MSC.json`.
- The project’s local `commanderDecklistsData.ts` currently contains skeletal entries (commander plus a few cards), so its current totals cannot represent full products. The MTGJSON deck download source should replace or backfill these entries before presenting complete all-card valuations.
- After filtering the official MTGJSON All Decks catalog to `Commander Deck`, the current page reports 190 results. The filtered results include the standard products and separate Collector’s Edition variants; the app should treat those as distinct printings only if the product catalog intentionally exposes them, otherwise use the standard deck as the canonical list and retain variant metadata separately.
- With the Commander Deck filter applied and Show All expanded, MTGJSON reports 190 entries and exposes the current product naming used by the official downloads. The live catalog confirms that several local names were stale or synthetic: Final Fantasy products are `Counter Blitz`, `Limit Break`, `Revival Trance`, and `Scions & Spellcraft`; Edge of Eternities products are `Counter Intelligence` and `World Shaper`; Tarkir Dragonstorm uses five clans; and collector editions are separately listed. Canonical ingestion should use the standard non-Collector JSON endpoints and preserve release date, commander, mainboard, source URL, and `sealedProductUuids` metadata.
- Official MTGJSON deck payload probe: `https://mtgjson.com/api/v5/decks/AvengersAssemble_MSC.json` contains 1 commander, 99 mainboard cards by quantity, `sealedProductUuids`, per-card `identifiers.scryfallId`, `setCode`, `number`, and retailer purchase URLs, but no direct `prices` object on the deck card records.
- Official MTGJSON set payload probe: `https://mtgjson.com/api/v5/MSC.json` includes `sealedProduct` records with `cardCount`, product name, release date, `uuid`, `tcgplayerProductId`, and purchase URLs, but no direct sealed MSRP field. Current sealed-price comparisons therefore need an explicit nullable sealed-price field and provenance rather than a fabricated default.
- The project price index currently has 79 daily signals and 175 Scryfall refresh products; that is not complete coverage for a 100-card Commander deck. Full-deck pricing must show priced/unpriced counts and should use a bulk Scryfall collection refresh or another explicitly timestamped source instead of treating missing snapshot rows as zero.
- MTGJSON’s official bulk price artifact is `https://mtgjson.com/api/v5/AllPricesToday.json.gz`. A streamed probe for a known Commander card UUID returned paper retail normal prices under `tcgplayer`, `cardkingdom`, and `cardmarket`, with a date key of `2026-08-21` and USD/EUR currency metadata. The implementation now uses this single bulk source rather than issuing hundreds of Scryfall collection requests, and selects TCGplayer first, then Card Kingdom, then Cardmarket as the displayed USD baseline while retaining vendor-level values for transparency.
